Capstone Self-Assessment Rubric

This isn't graded by anyone but you — but a rubric with no teeth is just a wish list. Score yourself honestly against each row before considering the capstone complete. capstone_checker.py automates the objective parts (consistency); this rubric covers the parts that require judgment.

Network design Segmentation is deliberate (not arbitrary), sized correctly via real subnetting math, and every isolation decision has a stated reason (not just "because Module 09 said so"). 04, 05, 09

The honest failure mode to watch for

It's easy to build something that LOOKS complete (every file exists, every checkbox ticked) without it being TRUE (the firewall rule you wrote doesn't actually match what you intended, the vulnerability you "remediated" wasn't re-tested, the incident report summarizes what you remember rather than what the evidence shows). capstone_checker.py catches some of this mechanically. The rest is on you — the entire point of a capstone is producing something you'd trust, not something that merely passes a checklist.
