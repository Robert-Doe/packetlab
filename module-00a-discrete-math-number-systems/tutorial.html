Module 00a — Tutorial

Goal: run the actual algorithms behind binary/hex conversion and modular arithmetic yourself, including a working Diffie-Hellman key exchange — before you need any of this for Module 04's subnetting or Module 13's cryptography.

Step 1 — base conversion, by hand

cd module-00a-discrete-math-number-systems
python number_systems.py
Expected: decimal/binary/hex conversions for several test values, a demonstration of the "4 bits per hex digit" shortcut, a worked subnet-mask-as-AND example matching Module 04's exact numbers (192.168.1.69/26), an XOR demonstration, and a 200/200 self-test confirming every hand-rolled function matches Python's own built-ins.
node number_systems.js
Identical output.

Step 2 — modular arithmetic and a real key exchange

python modular_arithmetic.py
Expected: a clock-arithmetic explanation, fast modular exponentiation verified against the naive method across 50 trials, and — the centerpiece — a working Diffie-Hellman exchange where Alice and Bob independently compute the identical shared secret without ever transmitting it.
node modular_arithmetic.js
A real bug caught during this module's build: the first version of the Node self-test used Math.pow() for the "naive" comparison and failed 46 of 50 trials — not because the fast method was wrong, but because JavaScript's number type (a 64-bit float) loses precision on integers with more than about 15-17 significant digits, and 1000^40 is a 120-digit number. Switching the naive comparison to BigInt (JS's arbitrary-precision integer type) fixed it. This is a genuinely important lesson in its own right — see tutorial2.html's section on floating-point limits.

Exercises before Module 00b

  1. Convert a real IP address by hand. Take your home network's gateway IP (from Module 01) and convert each octet to binary using decimal_to_binary(), then to hex using the 4-bits-per-digit shortcut. Cross-check with number_systems.py.
  2. Run the DH exchange with your own numbers. Pick a different (still small, still toy) prime and generator, and different private numbers for "Alice" and "Bob." Confirm both sides still converge on the same shared secret.
  3. Read tutorial2.html and tutorial3.html fully before moving to Module 00b — this module's real depth is there, not in this quick run-through.
